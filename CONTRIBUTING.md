# Contributing

This repository is primarily a professional portfolio and reference framework.

Suggestions, issues and improvements are welcome, especially around:

- Enterprise GenAI governance
- Secure model access
- GenAI operating models
- Architecture patterns
- Monitoring, risk and traceability
- Value and cost management
- Practical adoption roadmaps

## How to contribute

1. Open an issue describing the suggested improvement.
2. Explain the context and why the change would improve the roadmap.
3. For larger changes, propose a short outline before submitting a pull request.

## Contribution principles

Contributions should be:

- Practical and enterprise-oriented
- Clear enough for senior stakeholders
- Grounded in delivery, governance or operating model reality
- Vendor-neutral where possible
- Proportionate to risk and maturity

## What this repository is not

This repository is not intended to be:

- A vendor comparison
- A legal or regulatory opinion
- A complete security policy
- A production reference architecture
- A substitute for organisation-specific review
